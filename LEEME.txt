AROMAS ART - ARCHIVOS PARA GITHUB PAGES

Este ZIP contiene index.html y la carpeta bottles/ con las imágenes.

Para publicarlo: extrae el ZIP en tu dispositivo. En GitHub, entra al repositorio y sube/reemplaza index.html y sube la carpeta bottles con todos sus archivos. Deben quedar en la raíz del repositorio, así:

index.html
bottles/
  f-209-fantasy.jpg
  f-210-fantasy-in-bloom.jpg
  ...

No subas bottles.zip como un solo archivo: GitHub Pages no puede servir las imágenes que están dentro de un ZIP.
